# 项目简介
主要分为用户管理，会员管理，美发信息管理，预约管理，AI 理发助手，数据统计六个模块。用户管理可以实现增删查功能，支持用户账号的创建、删除和搜索，按页展示用户
列表，支持手机号/角色过滤，提升查询效率。会员管理采用分级管理，会员分为普通、银卡、金卡、钻石四个等级，便于管理员查询相应等级的会员。美发信息管理，拥有新增/修改/删除服务项目（如剪发、烫染），支持设置价格、时长、服务描述，并且能设置服务状态（启用/暂停），实时同步至前端展示。预约管理，查看所有预约订单，支持按日期、状态（待确认/已完成）筛选，如果理发师时间冲突，系统会自动检测，管理员可以手动调整预约时段。AI 理发助手，预设常见问题回复，快速相应客户咨询。数据统计，采用 CloudFlare 生成实时图表，便于管理员更加直观的了解订单以及用户情况，从而做出更好的经营决策，同时减少了管理员操作成本。


## 核心功能
- 用户管理：实现用户增删查功能，支持账号创建、删除和搜索，按页展示用户列表，支持手机号/角色过滤。
- 会员管理：分级管理会员，分为普通、银卡、金卡、钻石四个等级，便于查询相应等级的会员。
- 美发信息管理：新增/修改/删除服务项目，支持设置价格、时长、服务描述，并设置服务状态（启用/暂停）。
- 预约管理：查看所有预约订单，支持按日期、状态（待确认/已完成）筛选，自动检测理发师时间冲突，支持手动调整预约时段。
- AI 理发助手：预设常见问题回复，快速响应客户咨询。
- 数据统计：采用 CloudFlare 生成实时图表，便于管理员直观了解订单及用户情况。

## 适用场景
- 智能理发店运营管理
- 提高客户服务效率
- 实现高效会员管理
- 简化预约流程
- 提升经营管理决策

## 技术特点
- 基于 SpringBoot 框架，确保系统稳定性和扩展性
- 使用 CloudFlare 进行数据统计，图表展示直观易读
- AI 理发助手快速响应客户咨询，提高客户满意度
